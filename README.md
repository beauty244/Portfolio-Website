# Beauty Rani – Personal Portfolio

A modern, responsive portfolio for **Beauty Rani** (B.Sc. IT Student | Aspiring Software Developer), built with HTML, CSS, and JavaScript only.

## Features

- **Sections**: Navbar, Hero, Profile, Education, Skills (categorized cards), Certifications & Experience, Projects (placeholders), Languages (badges), Contact, Footer
- **Design**: Modern minimalist, soft gradient accents, rounded cards, clean typography, subtle animations, dark/light mode, student-friendly and professional
- **Functionality**: Sticky navbar, smooth scrolling, mobile hamburger menu, dark/light toggle, scroll reveal animations, typing animation in hero, contact form with validation, active nav highlighting, lazy-loaded images

## How to Run Locally

1. **Option A – Open directly**  
   Double-click `index.html` or open it in your browser (File → Open).

2. **Option B – Local server (recommended)**  
   In the project folder, run one of these in a terminal:

   **Node (npx):**
   ```bash
   npx serve .
   ```
   Then open the URL shown (e.g. http://localhost:3000).

   **Python 3:**
   ```bash
   python -m http.server 8000
   ```
   Then open http://localhost:8000

   **PHP:**
   ```bash
   php -S localhost:8000
   ```
   Then open http://localhost:8000
